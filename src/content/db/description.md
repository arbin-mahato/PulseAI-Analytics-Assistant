TradeLab metric catalog
=======================

All data generated by the default seed is synthetic, denominated in INR, with timestamps in Asia/Kolkata. The dataset_info table records its as-of time and seed. Every metric table has one row per client. NULL means unavailable or an undefined denominator; zero is a known zero. Monetary values are numeric, flags are Boolean, and identifiers are strings.

The original ClickHouse SQL is retained in script/queries/legacy-clickhouse for reference. The active SQL uses consistent BUY/SELL values and matched-fill realized P&L, with typed results and explicit windows.

**identity_and_lifecycle**

| Column | Definition |
|---|---|
| client_id | Alphanumeric synthetic client identifier; join metric tables on this column. |
| name | Full name of the user for identification |
| email | Primary email address of the user |
| first_trade_date | Date of the user's first recorded trade |
| days_since_first_trade | Number of days since the user's first trade (cohort analysis) |
| last_calculated_at | Timestamp when this metric row was last updated |
| days_since_last_seen | Number of days since the user was last active (churn risk indicator) |
| primary_platform_30d | Device platform with most events in last 30 days (web/ios/android) |
| is_multi_platform_user_30d | Flag (1/0) if user was active on multiple platforms in last 30 days |
| unique_ip_count_30d | Number of unique IP addresses used in last 30 days |
| latest_app_version_used | Most recent app version recorded on user's events |
| signup_date | Date when user's account was first created |
| account_age_days | Total days user has been registered on platform |
| activation_status | Whether user has made at least one deposit (Activated/Not Activated) |
| active_days_30d | Number of unique days user was active in last 30 days |
| avg_time_since_last_activity_per_login | Average gap in days between consecutive logins |
| distinct_login_ids_90d | Number of unique login_id values in last 90 days |
